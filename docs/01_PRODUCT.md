# 제품 명세

설계 기준일: 2026-10-14
상태: 구현 전 제안 명세. 이 패키지는 완성된 애플리케이션이나 실행 검증된 코드가 아니다.

## 1. 목표

단순한 당첨자 추첨기가 아니라 누구나 코스를 만들고 구슬을 꾸며 함께 즐길 수 있는 2D 구슬 레이스 제작 서비스를 만든다. Next.js 기반 웹으로 시작한다. 로그인하지 않아도 기본 맵 플레이와 로컬 맵 제작을 할 수 있고, 로그인하면 클라우드 저장과 공유를 이용한다.

핵심 경험은 `템플릿 선택 → 코스 수정 → 테스트 플레이 → 이름과 구슬 설정 → 게시 → 링크 공유 → 다른 사람이 플레이하거나 리믹스`다.

원본 마블룰렛의 공개 사이트도 현재 웹 맵 에디터와 공유마당을 안내한다. 따라서 세 기능의 유무만을 차별점으로 내세우지 않는다. 차별화 가설은 쉬운 제작 흐름, 완성도 높은 구슬 꾸미기, 원본 출처가 유지되는 리믹스, 맵 버전과 공유 공개범위를 이해하기 쉬운 UX다. 가설의 효과는 실제 사용자 테스트로 확인한다. [P1]

독립적인 화면, 템플릿, 그래픽, 이름을 만든다. 원본 코드를 복사하는 경우 파일별 출처와 라이선스 고지를 남긴다. 원본 저장소는 MIT를 소스 코드에 적용하며 명칭 사용은 별도로 제한한다고 설명한다. 이 문서는 해당 저장소의 안내를 인용한 것이며 상표 등록 현황에 대한 독립적인 법률 검증은 아니다. [P2]

## 2. 초기 출시 범위

| 영역 | 첫 출시의 필수 기능 | 이후로 미룰 기능 |
|---|---|---|
| 레이스 | 2~100명, 중복 이름 허용과 고유 ID, 시작/일시정지/재시작, 카메라 이동, 순위, 시간 초과 | 가중치 추첨, 베팅, 실시간 참가자 조작 |
| 맵 | 독자 템플릿 3종, 벽, 원형 장애물, 범퍼, 회전봉, 왕복 발판, 출발 구역, 결승선 | 자유 곡선, 포털, 줄과 관절, 사용자 스크립트 |
| 에디터 | 배치, 선택, 이동, 회전, 크기, 복제, 삭제, 다중 선택, 스냅, Undo/Redo, 테스트 모드 | 동시 공동 편집, 완전한 모바일 편집기 |
| 꾸미기 | 단색, 기본 패턴, 이모지, 사진 원형 크롭, 이름 표시, 저장 스킨 | 스킨 거래, 복잡한 입자와 셰이더, 사용자 폰트 |
| 저장 | IndexedDB 로컬 저장, JSON 백업, 로그인 후 클라우드 저장 | 완전한 오프라인 PWA, 다중 기기 자동 병합 |
| 공유 | 공개 맵 상세, 링크 전용 공유, 버전 고정, 레이스 설정 공유, 결과 요약 링크 | 동시 관전 방, 동영상 생성, 검증된 서버 리플레이 |
| 탐색 | 공개 맵 최신순, 제목 검색, 기본 태그, 상세와 리믹스 | 개인화 추천, 팔로우, 댓글, 인기 순위 조작 대응 시스템 |
| 운영 | 콘텐츠 신고, 서버 권한 기반 비공개 처리, 업로드 제한, 오류 모니터링 | 결제, 광고, 창작자 정산 |

100명은 검증을 목표로 하는 초기 상한이지 성능 보장 수치가 아니다. 모바일 기본 추천은 30명이다. 성능 계측 결과에 따라 출시 상한을 낮출 수 있으며 변경은 문서와 UI에 함께 반영한다.

## 3. 역할과 권한

비회원은 공개 맵과 유효한 공유 링크를 플레이할 수 있다. 로컬 에디터, 기본 꾸미기, 로컬 사진, JSON 가져오기와 내보내기는 로그인 없이 사용할 수 있다. 로컬 데이터가 다른 기기에 동기화되거나 영구 보존된다고 표시하지 않는다.

회원은 자신의 맵, 스킨, 공유 링크를 관리한다. 다른 사람의 맵은 허용된 게시 버전을 읽거나 리믹스할 뿐 원본을 편집할 수 없다. 첫 인증 방식은 이메일 로그인 하나로 한정하고, 소셜 로그인은 이후에 추가한다.

관리자는 서버가 검증한 권한으로 게시물과 이미지 노출을 중단하고 신고 상태를 변경한다. 사용자 수정 가능한 프로필 필드나 클라이언트 플래그를 관리자 권한으로 사용하지 않는다.

## 4. 화면과 주요 흐름

| 경로 | 목적 | 기본 동작 |
|---|---|---|
| `/` | 시작 화면 | 바로 플레이, 맵 만들기, 공개 맵 탐색 |
| `/play` | 로컬 레이스 | 기본 맵, 이름 입력, 꾸미기, 플레이 |
| `/play/[versionId]` | 공개 게시 버전 플레이 | 권한 확인 후 고정 버전 로드 |
| `/editor/new` | 신규 로컬 초안 | 빈 코스 또는 템플릿에서 시작 |
| `/editor/local/[draftId]` | 로컬 초안 수정 | 해당 브라우저의 IndexedDB 사용 |
| `/editor/[mapId]` | 클라우드 초안 수정 | 로그인과 소유권 필요 |
| `/maps` | 공개 맵 탐색 | 최신순과 제목 검색, 페이지네이션 |
| `/maps/[mapId]` | 현재 게시판 상세 | 최신 게시 버전, 제작자, 리믹스 출처 |
| `/maps/[mapId]/v/[versionNo]` | 고정 버전 상세 | 과거 게시 버전도 식별하되 현재 공개 권한 확인 |
| `/s/[token]` | 링크 전용 공유 | 맵, 설정, 결과 중 하나의 최소 DTO 제공 |
| `/me/maps` | 내 맵 | 초안, 공개 상태, 공유 링크 관리 |
| `/me/skins` | 내 스킨 | 기본 스킨과 사진 스킨 관리 |
| `/settings` | 계정 | 데이터 삭제 요청과 계정 설정 |

에디터는 데스크톱에서 좌측 오브젝트 팔레트, 중앙 캔버스, 우측 속성 패널, 상단 저장/테스트/게시 버튼으로 구성한다. 모바일 첫 출시는 플레이, 참가자 설정, 탐색, 공유를 우선한다. 작은 화면의 에디터는 미리보기와 단순 속성 변경 수준으로 제한하고 데스크톱 편집 안내를 제공한다.

텍스트 입력 중에는 Delete, Space, Ctrl+Z 등의 에디터 단축키가 작동하지 않아야 한다. 터치 조작은 버튼과 숫자 입력으로 대체할 수 있어야 한다. 모션 축소, 음소거, 이름 가독성, 키보드 포커스를 포함한다. 캔버스 바깥에도 참가자 목록과 결과를 DOM 텍스트로 제공한다.

## 5. 공유의 의미

맵 공유는 코스만 전달한다. 참가자의 이름과 사진은 절대 포함하지 않는다.

레이스 설정 공유는 게시 맵 버전과 규칙, 인원, 선택적으로 이름과 스킨을 전달한다. 기본값은 익명 이름과 기본 구슬이다. 실제 이름과 사진을 포함하려면 공유 미리보기에서 명시적으로 선택해야 한다. 받는 사람이 실행하는 레이스는 별도의 실행이다. 같은 시각에 진행되는 방이 아니다.

결과 공유는 완료한 레이스의 순위 요약을 전달한다. 초기 결과에는 `사용자 기기에서 생성한 결과, 서버 검증 안 됨`을 표시한다. 결과 링크는 영상이나 조작 방지 증명이 아니다.

공개 범위는 다음처럼 정의한다.

| 값 | 의미 |
|---|---|
| `private` | 소유자만 접근, 유효한 외부 공유 링크 없음 |
| `unlisted` | 탐색과 검색에 노출하지 않음. 충분히 긴 토큰을 가진 사람만 공유 경로로 접근 |
| `public` | 공개 탐색과 상세 페이지에서 누구나 접근 |

초안은 맵 공개 여부와 무관하게 항상 소유자 전용이다. 링크 전용은 수신자가 링크를 다시 전달할 수 있다는 의미이며 비밀 보관을 보장하지 않는다.

## 6. 게임 규칙

모든 참가자는 동일한 반지름과 물리 특성을 가진 구슬 하나를 받는다. 슬롯 배정은 시드 기반 무작위 순열을 사용한다. 사진과 스킨은 물리 특성에 영향을 주지 않는다.

결승선 통과 순위는 시뮬레이션 tick과 해당 tick 안에서 추정한 통과 비율로 결정한다. 정밀도 범위에서 같은 값은 공동 순위로 처리한다. 내부 ID 순서를 당첨 우선순위로 사용하지 않는다.

선택 가능한 결과 규칙은 1위, 지정 순위, 마지막 완주다. 공동 순위이면 공동 대상자를 표시한다. 시간 초과나 코스 이탈은 DNF로 별도 표기한다. 미완주자가 있을 때 마지막 완주를 전체 꼴찌라고 표시하지 않는다.

제한 시간은 초기 기본 120초의 시뮬레이션 시간이다. 2배속은 실제 대기 시간을 줄일 뿐 물리 계산 간격이나 게임 내 제한 시간을 바꾸지 않는다. 종료 후 `새 레이스`는 새 시드를, `같은 조건 다시 실행`은 동일한 시드를 사용한다.

## 7. 게시와 리믹스

게시 전에는 JSON 구조, 오브젝트 제한, 출발 슬롯 수, 결승선, 좌표 범위, 에셋 상태를 검증한다. 작성자가 실제 테스트 플레이를 실행하지 않았다면 게시 UI에서 안내한다. 이 테스트는 브라우저 실행 결과이므로 서버가 인증한 코스 안전성으로 홍보하지 않는다.

초안 저장은 게시 버전을 바꾸지 않는다. 게시 버튼을 누를 때만 새로운 불변 버전을 만든다. 과거 공유 링크는 기존 버전을 계속 가리킨다. 다만 소유자가 비공개로 바꾸거나 관리자가 숨기면 이전 버전도 외부 접근을 차단한다.

리믹스는 현재 접근 가능한 게시 버전에서 새 소유자의 새 맵을 만드는 작업이다. `source_version_id`로 출처를 보존한다. 초기 정책은 제작자가 `allow_remix`에 동의한 맵만 리믹스 허용이다. 기술적으로 내려받은 JSON의 재사용을 완전히 막는 DRM은 제공하지 않는다. 원본의 공개 중단이 이미 생성된 독립 리믹스를 자동 삭제하지 않는다는 정책을 고지하되 권리 침해 신고는 별도로 처리한다.

## 8. 성공 지표와 운영 비용

첫 플레이 성공률, 에디터 진입 대비 테스트 플레이 비율, 테스트 대비 게시 비율, 공유 링크 수신자의 플레이 비율, 반복 방문을 측정 후보로 둔다. 수집은 동의와 보존 정책에 맞추며 이름, 사진, 원본 참가자 명단, 공유 토큰을 분석 이벤트에 포함하지 않는다.

목표치는 서비스 사용 데이터를 얻기 전에는 확정하지 않는다. 출시 전에는 UX 테스트에서 사용자가 도움 없이 템플릿을 수정하고 테스트하고 공유할 수 있는지 확인한다.

게임 중 프레임 좌표는 서버로 전송하지 않는다. 비용은 주로 웹 전송, 인증, DB 조회, 이미지 저장과 다운로드에서 발생하도록 설계한다. Vercel의 Hobby는 공식 문서상 비상업적 개인 용도에 한정되므로 상업 서비스 운영 시 적합한 플랜을 별도로 확인한다. 비용을 무료로 보장하지 않는다. [P3]
